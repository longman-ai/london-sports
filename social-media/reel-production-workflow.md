# London Sports Community - Reel Production Workflow

> Using Final Cut Pro (Mac/iPad) + Apple Creator Studio Pro
> Goal: Batch-produce 2 weeks of reels in one session (~8-10 reels)

---

## Setup (One-Time, ~30 min)

### 1. Create Your FCP Library
- Open Final Cut Pro
- Create a new Library: `LDN Sports Reels`
- Create Events by month: `March 2026`, `April 2026`, etc.
- Set default project settings: **1080x1920 (9:16 vertical)**, 30fps

### 2. Build Your Template Project
Create one master project with these layers (top to bottom):
- **Text overlay layer** (for captions/hooks)
- **Main video/photo layer**
- **Background layer** (emerald gradient or solid #059669)
- **Music layer**

Save this as a template - duplicate it for each new reel.

### 3. Create Motion Templates (Optional but Pro)
Using **Motion** (included in Creator Studio):
- **Branded intro:** 2-sec emerald swoosh with "London Sports Community" logo
- **Lower third:** Name/sport/borough bar in emerald
- **End card:** "Find your group - link in bio" with logo
- Export as FCP templates so they're always in your effects browser

### 4. Stock Assets Folder
Create a folder structure on your Mac:
```
LDN-Sports-Reels/
├── templates/          # Motion templates
├── music/              # Royalty-free tracks (see below)
├── footage/            # B-roll clips
│   ├── football/
│   ├── running/
│   ├── padel/
│   └── general-london/
├── screenshots/        # Website screenshots for walkthroughs
└── exports/            # Final exported reels
```

## The 5 Reel Formats

### Format 1: "POV: Your Mate Asks..." (Shareability Play)
- **Length:** 15-20 sec
- **Hook:** Text on screen "POV: your mate asks where to play football in [Borough]"
- **Body:** Quick scroll through groups on the website (screen recording)
- **CTA:** "Link in bio - it's free"
- **Why it works:** DM shares are #1 algorithm signal in 2026. People literally send these to mates

### Format 2: Borough Spotlight
- **Length:** 20-30 sec
- **Hook:** "I found every sports group in [Borough]"
- **Body:** Map zoom into borough + scroll through available groups
- **CTA:** "Which borough should I do next? Comment below"
- **Why it works:** Local content gets saved and shared. Comments boost reach

### Format 3: Sport Guide
- **Length:** 15-25 sec
- **Hook:** "Best [sport] groups in London"
- **Body:** Quick cuts of 3-5 groups with name/location overlay
- **CTA:** "All free to browse - link in bio"
- **Why it works:** Targets people searching for specific sports

### Format 4: How-To Walkthrough
- **Length:** 20-30 sec
- **Hook:** "Finding a sports group in London takes 10 seconds"
- **Body:** Screen recording of browsing the site, filtering by sport/borough
- **CTA:** "Try it yourself - link in bio"
- **Why it works:** Product demo disguised as helpful content

### Format 5: Group Owner Spotlight
- **Length:** 25-30 sec
- **Hook:** "[Group name] runs [sport] every [day] in [area]"
- **Body:** Quick info about the group, what to expect, how to join
- **CTA:** "Found on London Sports Community - free directory, link in bio"
- **Why it works:** Group owners share it with their members = instant reach

## Batch Production Workflow

### Phase 1: Script & Plan (~30 min)
1. Pick 8-10 reels from the formats above
2. Write the hook text for each (this is the most important part)
3. Note which boroughs/sports/groups each reel covers
4. Assign a music track to each

### Phase 2: Capture (~45 min)
1. **Screen recordings:** Open the website on your phone, record yourself browsing relevant pages. Do all screen recordings in one go
2. **Map clips:** Screen record Google Maps zooming into each borough
3. **B-roll (optional):** Film any local sports footage if you're near a park/court
4. **Voiceover:** Record all voiceovers in one session using Voice Memos. Keep it casual, like talking to a mate. Script the first line (hook), wing the rest

### Phase 3: Edit in FCP (~2-3 hours for 8-10 reels)
For each reel:
1. Duplicate your template project
2. Drop in screen recording / footage
3. Add voiceover
4. Add text overlay (hook text - big, readable, centred)
5. Add branded intro (2 sec) and end card (3 sec)
6. Add lower third for any group/borough names
7. Add music (duck under voiceover)
8. Trim to 15-30 seconds
9. Export: H.264, 1080x1920, Best Quality

**FCP Speed Tips:**
- Use Blade tool (B) to quick-cut between clips
- Use the Range tool to select and delete dead space
- Copy/paste colour corrections across all reels
- Use Compound Clips to group your text + background layers
- Use Roles to organise voiceover vs music vs SFX

### Phase 4: Export & Schedule (~20 min)
1. Export all reels to your `exports/` folder
2. AirDrop to your phone (or use iCloud)
3. Upload to IG and TikTok
   - **IG:** Schedule via Meta Business Suite (up to 75 days out)
   - **TikTok:** Schedule via TikTok Studio (up to 10 days out)
4. Add captions, hashtags, and sounds in-app

## Voiceover Tips

- **Be casual.** Talk like you're telling a mate about it, not presenting
- **Start with energy.** The first 2 seconds decide if someone keeps watching
- **Keep it short.** 15 words per clip max. Let the visuals do the work
- **Record in a quiet room.** Bathroom acoustics actually work well
- **Use your normal accent.** Authenticity > polish
